Markdown Studio for Confluence

Edit any Confluence page as Markdown, paste Markdown as a real page, and import a whole Obsidian vault into a page tree.

Getting started

Install the app from the Atlassian Marketplace. There is nothing to set up afterwards: the app works in every space you can already see and edit, and every change is made as you, with your own Confluence permissions.

You'll find the app in two places:

  • On any page, click Markdown under the page title to edit that page as Markdown. The same action is in the page's ••• menu under Apps → Edit as Markdown.
  • In the top bar, open Apps → Markdown Studio to create a page from Markdown or import an Obsidian vault.

Edit a page as Markdown

The editor opens with the page's Markdown on the left and a live preview on the right. Change the text and click Save. The page gets a new version, so you can compare or restore it from the page history as usual.

What happens to things Markdown can't express

Macros, mentions, dates, status lozenges, emoji, layouts, text colors and tables with merged cells are kept. In the editor they show as small locked chips, such as @Jane Doe or Jira issues. Leave a chip where it is, move it, or delete it, and it is saved exactly as it was. Settings that wrap normal text, such as a layout's columns or a table's width, show as small gray labels. Keep the labels around the text they belong to.

If someone else saves the page while you're editing, the app tells you instead of overwriting their change. Copy your Markdown, reload the page and try again.

Create a page from Markdown

  1. Open Apps → Markdown Studio and stay on New page from Markdown.
  2. Choose the space and, if you like, a parent page.
  3. Paste or type Markdown. The preview shows the page exactly as it will be saved.
  4. Check the title. It is taken from the front matter title: or the first top-level heading, and you can type your own.
  5. Click Create page.

Supported: GitHub-flavored Markdown, including tables, task lists, strikethrough and code blocks with a language. Callouts such as > [!NOTE] become Confluence panels. Tick Obsidian syntax when the text comes from Obsidian: single line breaks are kept, ==highlights== are highlighted, %%comments%% are left out, and #tags become page labels.

Import an Obsidian vault

  1. Zip your vault folder. On a Mac, right-click the folder and choose Compress. On Windows, right-click it and choose Send to → Compressed (zipped) folder.
  2. Open Apps → Markdown Studio → Import an Obsidian vault and choose the zip.
  3. Choose the space and a parent page. The vault is created under that page.
  4. Click Check the vault. Nothing is written yet. The check lists how many pages and files will be created, pages that get a new title, and links or files it can't find.
  5. Click Import and keep the tab open until it finishes. When it's done, Open the pages takes you to them.

Good to know

  • Page titles must be unique in a Confluence space. If a note's title is already taken, the page gets its folder's name in brackets, or a number.
  • The .obsidian settings folder and other hidden files are skipped, and so are canvas and Excalidraw drawings.
  • If an import stops, for example because the tab was closed, choose the same zip, space and parent page again. The app offers to continue where it stopped, without making duplicate pages.
  • The zip is read in your browser. It is never uploaded anywhere except, page by page, to your Confluence site.

Questions

Who can use the app?

Everyone on a site where it's installed. People can only open, edit and create pages they could already open, edit and create in Confluence.

Does the app send my content anywhere?

No. The app runs on Atlassian's Forge platform and has no servers of its own. See the privacy policy.

Why did a warning appear above the preview?

The app tells you when part of the Markdown can't become Confluence content, such as raw HTML (kept as a code block), a link Confluence rejects (kept as text), or a wikilink to a note that isn't in the vault. Everything else is saved.

The app says it needs a subscription

Sites with up to 10 users use the app for free. Larger sites need an active subscription. A site admin can start or renew it from the app's Marketplace listing or from Manage apps in Confluence's settings.
